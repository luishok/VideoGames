# 01 - Pong

Proyecto desarrollado como parte de la materia *Programación de Videojuegos I* (ULA).

## Descripción
Implementación clásica del juego Pong utilizando el motor **Gale** y Pygame, aplicando conceptos de bucle de juego, gestión de estados y detección de colisiones básicas entre la pelota y las paletas.

## Controles
- **Jugador 1 (Izquierda):** W / S
- **iA 2 (Derecha)
- **Reiniciar / Servir:** Enter

## ¿Cómo ejecutarlo?
1. Asegúrate de haber activado el entorno virtual y tener instaladas las dependencias en la raíz del repositorio.
2. Ubícate en esta carpeta desde tu terminal:
   ```bash
   cd 01-pong
   python main.py
