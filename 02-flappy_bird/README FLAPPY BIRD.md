# 02 - Flappy Bird

Proyecto desarrollado como parte de la materia *Programación de Videojuegos I* (ULA).

## Descripción
Implementación clásica del juego Flappy Bird utilizando el motor **Gale** y Pygame. Este estudio de caso profundiza en la aplicación de física de gravedad, desplazamiento y la gestión de estados del juego (menú, juego activo, pausa y fin de partida).

## Controles
- **Menú Principal:** 
  - `1` Modo Normal
  - `2` Modo Difícil
- **Modo Normal:**
  - `Barra Espaciadora` Saltar
- **Modo Difícil:**
  - `Flecha Izquierda` / `Flecha Derecha` 
  - `Barra Espaciadora`  Saltar
- **General:**
  - `P`  Pausar / Continuar
