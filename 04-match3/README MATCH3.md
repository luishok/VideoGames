# 04 - Match-3

Proyecto desarrollado como parte de la materia *Programación de Videojuegos I* (ULA).

## Descripción
Implementación de un juego de rompecabezas tipo Match-3 utilizando el motor **Gale** y Pygame. Este proyecto explora la lógica de matrices/tableros bidimensionales, algoritmos de detección de coincidencias (matches de 3 o más elementos), animaciones de intercambio, caída de piezas y gestión de puntuación.

## Controles
- **Selección e Intercambio:**
  - `Clic Izquierdo` Seleccionar y arrastrar o hacer clic en piezas adyacentes para intercambiarlas.
