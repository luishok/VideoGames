# 05 - Super Martian

Proyecto desarrollado como parte de la materia *Programación de Videojuegos I* (ULA).

## Descripción
Juego de plataformas (*Platformer*) desarrollado con el motor **Gale** y Pygame. Este estudio de caso se enfoca en la gestión de gravedad, colisiones de plataformas, animaciones de personajes y progresión de niveles con objetivos específicos:
- **Nivel 1:** Alcanzar una puntuación de 100 puntos para avanzar.
- **Nivel 2:** Alcanzar una puntuación de 200 puntos y recolectar la llave oculta dentro de un bloque secreto para completar el juego.

## Controles
- **Movimiento:**
  - `Flecha Izquierda` / `Flecha Derecha` Mover al personaje horizontalmente.
- **Acciones:**
  - `Barra Espaciadora` Saltar.
- **General:**
  - `P` Pausar / Continuar
